## New

- **A tab's right-click menu is native,** for one tab or several selected: pin, move to Pinned or Top Apps, groups,
  and moving tabs to another profile or window each happen in one step. Duplicating several tabs is one step too.
- **Imports from Arc and Zen run natively** when you bring over bookmarks, history and passwords without their tabs
  or spaces. `defaults write network.benson.solara ImportRoute script` still switches back to the previous importer.

## Fixed

- **A crash while typing in a field Solara updates on its own** should be gone: the address field, the Command Bar,
  tab search and Settings search keep the cursor inside the text when Solara replaces it. Please report it if it
  happens again.
- **VoiceOver reads the top strip's + as a button** again, not as an unselected option.
