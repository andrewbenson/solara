## New

- **Agents can look at your browser.** `solara mcp` lets Claude Code, Codex or Cursor list your tabs, search your
  history and read a page; `solara mcp install` sets it up for one of them. It only reads unless you start it with
  `--allow-actions`, and it never runs commands.
- **The `solara` command lists and finds things.** `solara profiles`, `solara windows` and `solara tabs` show what's
  open, `solara find` searches your tabs, pins and history, and `solara open` opens a link without bringing Solara
  forward.
- **Pinch to resize Picture in Picture from any app.** Pinching or ⌘-scrolling over the video works even when
  another app is in front.

## Faster

- **Solara starts faster.** It no longer prepares the profile icon picker in every window at launch, which made
  0.4.2 start slower than 0.4.1.
- **New windows appear sooner.** A new window shows as soon as its page exists instead of waiting for parts of the
  sidebar.

## Fixed

- **⌘T on a blank New Tab page opens the Command Bar again.** With New tabs set to open the Command Bar, ⌘T opened
  another tab instead, and the Command Bar's New Tab row didn't make a tab right away.
- **The clean-up suggestion can stop asking.** The card has a Don't Ask Again, and Settings › Tabs has Suggest
  cleaning up old tabs; the card was also upside down, with its buttons above its title.
- **The profile bar shows every profile's icon.** Each profile sits in the same size slot with its own icon,
  dimmed until you pick it, and its tooltip now opens above the bar instead of running off the window.
- **The tab numbers stay up while you hold ⌘.** Pressing ⌘ and a number switches the tab and keeps the keycaps
  showing until you let go.

## Smaller

- The sidebar's tabs now fade out behind the profile icons instead of above them.
