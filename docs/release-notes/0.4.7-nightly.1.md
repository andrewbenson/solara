## New

- **History is kept until you clear it.** Solara no longer deletes browsing history after 90 days, and history you
  import from another browser comes in whatever its age. Clear Browsing Data still removes all of it. Sync still
  carries the last 90 days between your Macs.
- **Imports from Chrome, Edge, Brave, Vivaldi and Firefox, and from a bookmarks HTML file, run natively.** If an
  import from one of them goes wrong, run `defaults write network.benson.solara ImportRoute script` in Terminal to use
  the previous importer, and please report it; `defaults delete network.benson.solara ImportRoute` switches back.
- **⌘T and + New Tab open in the + New Tab row itself,** with no extra blank row. Typing or going somewhere turns it
  into a tab; an untouched one goes away when you leave it.

## Fixed

- **A session Solara can't open gets a clear window instead of a blank one.** It offers to open in safe mode,
  after two failed launches the next one opens in safe mode on its own, and no window appears behind it first.
- **The mini player stays put while you swipe between profiles,** and its card no longer says "In PiP".
- **History you import while your history list is loading stays in the list.**
