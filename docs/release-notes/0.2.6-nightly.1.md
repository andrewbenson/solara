## Fixed

- **Editing an address keeps your place.** Typing inside a URL in the address bar no longer throws the cursor to the end after every character.
- **Going back to a page you started on works the first time.** A navigation back to the page a tab first opened, after the page had moved on (say, back to a sign-in page after signing in), no longer does nothing.
- **Quitting doesn't crash.** A shutdown crash after using private windows is gone; Solara turns off a Chrome service it never used.
