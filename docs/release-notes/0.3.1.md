## New

- **See every tab's memory from the terminal.** `solara tabs` lists each open tab with its memory, title, address and profile, largest first, with a total at the bottom. Sleeping tabs show a dash and stay asleep. It works while "Let the solara command control Solara" is on, and `--json` gives the same list to scripts.
- **Solara runs Chromium 157.** It brings the security fixes and site compatibility of Chrome 157, up from 156.

## Smaller

- The toolbar sits directly on the window frame, with no band or gradient of its own.
- Switching tabs does less work in the background.
- Memory readings in tab hover cards are forgotten when a tab closes or moves to another page.
- A rare crash when quitting while a deleted profile's data was still being cleared is gone.
