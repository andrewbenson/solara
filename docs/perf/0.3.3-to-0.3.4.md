# 0.3.3 → 0.3.4 release gate

0.3.4 (build 100, v0.3.4 on 5a8c167e) carries engine ecd8168076bd (Chromium 157.0.8103.50) and keeps native API 43, so
native-bench ran the candidate's bundle on both apps and js-bench each app's own `main.jsbundle`. Candidate
`dist/0.3.4/export/Solara.app` (signed and notarized); control `dist/0.3.3/export/Solara.app`. Both with
`SOLARA_NATIVE_BOOKMARKS=1`, ad hoc copies on both sides (`BENCH_SIGN_IDENTITY=-`), measured on 2026-11-13 on the Hill
Studio under the perflab lock, interleaved, screen locked (paint and frame rows pending). native-bench: launch x6,
session and windows x2. js-bench: three alternating runs per app.

It failed the gate's "same or better" rule on the rows under Worse; the owner chose to ship it. The rows 0.3.3 lost
are all back, most of them well past 0.3.2.
