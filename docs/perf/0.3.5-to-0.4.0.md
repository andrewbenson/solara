# 0.3.5 → 0.4.0 release gate

0.4.0 (build 102, candidate 0bb37b18) keeps engine bda8c434d8f6 (Chromium 157.0.8103.50) and moves native API 43 → 64,
so native-bench ran each app with its own bench bundle (0.3.5's built from `v0.3.5` and compiled with the candidate's
hermesc) and js-bench each app's own `main.jsbundle`. Candidate `dist/0.4.0/export/Solara.app` (signed and
notarized); control the retained 0.3.5 export. Both with `SOLARA_NATIVE_BOOKMARKS=1`, ad hoc copies on both sides
(`BENCH_SIGN_IDENTITY=-`), offline, measured on 2026-11-15 on the Hill Studio under the perflab lock, interleaved,
screen awake and unlocked. native-bench: launch x6, session and standalone windows x2 per app. js-bench: three
alternating runs per app.

**Shipped by the owner's call past five rows** (2026-11-15, "Ship now, fix in 0.4.1").

The first candidate (86366de9, native window layout on by default) failed: tab switch 39 → 90 ms, new tab first paint
101 → 152 ms, new window 99 → 134 ms, and 23 ratchet counts. The gate fixes (d2124d5b) brought the ratchet back but not
the timings; a traced fix of the run-loop hops between layout, pool reconciliation and paint was rejected by its own
paired timing (tab switch 48 vs 40 ms, new tab 143 vs 95 ms). By the owner's rule the release went out with the native
window layout off by default (4eb72e45); this is that build.

Smoke: 70/70 in the desktop session, including the Sparkle update from 0.3.5, carryover and the key-event checks.
Ratchet: ok (seven mount ceilings raised in 4eb72e45 for layout port 8's Legacy* wrappers). Host harnesses: 11/12;
sheet-host fails "ending busy must allow dismiss" on NativeSheets.swift and a harness unchanged since v0.3.5 (it failed
the same way on the first candidate) — a follow-up.

## Worse (more than 15%, separated ranges)

| row | 0.3.5 | 0.4.0 |
|---|---|---|
| new window → on screen | 97 ms (92–104, n=4) | 135 ms (120–150, n=4) |
| tab switch → shown | 36 ms (31–41, n=2) | 42 ms (42–43, n=2) |
| js pageLoad.stalls.totalMs | 348 [323–355] | 547 [486–557] |
| js profileSwipe.stalls.totalMs | 1108 [1099–1135] | 1308 [1256–1328] |
| js startup.bundleToFirstWindowMs | 73 [68–77] | 350 [342–356] |

bundleToFirstWindowMs changed its boundary in layout port 10 (the first window is now native chrome's committed frame,
not a React root effect); launch → window shown, the user-facing row, is 723 → 796 ms (+10%). The others are
unattributed and go to 0.4.1, whose gate re-enables the native layout.

CPU and memory within noise; js typing stalls 386 → 184 ms, hover 300 → 149 ms, switchTabs 914 → 853 ms,
openClose 1960 → 1838 ms.
