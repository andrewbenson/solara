date: 2026-11-10
headline: Bookmarks now live where the browser keeps them.
---

Solara 0.3.0 moves bookmarks into the native side of the app: the bar, its menus and every edit now go straight to Chrome's own bookmark store. After opening 0.3.0, going back to 0.2.5 isn't supported.

## New

- **Heavy tabs say so.** A tab whose CPU or memory stays high gets a small badge in the sidebar, and its hover card offers Put to Sleep. The hover card also shows how much memory each tab uses.
- **The bookmarks bar is native.** Bookmark menus, keyboard navigation, VoiceOver actions and dragging links or tabs onto the bar all run in the native bar, and every bookmark edit, from ⌘D to imports, is written once, by the browser.
- **Screen sharing no longer covers the page.** The bar that appears while a site shares your screen now pushes the page down instead of sitting over its top edge.
- **The page sits on the window frame with a soft edge.** A faint hairline and a gentle shadow, tinted to the profile's colour in light mode, separate the page from the frame.

## Fixed

- **Deleted bookmarks stay deleted.** A bookmark removed while a sync push failed partway could come back after a restart. Pending deletions now survive restarts until Chrome has caught up.
- **Moving bookmarks never loses them.** Move to Bookmark Bar, Restore Arc Folders and imports only remove the original once the new place has been saved, and an import that finds the bar changed under it plans again.
- **The toolbar keeps up when you resize the sidebar.** Dragging the sidebar's edge moved the page at once while the toolbar trailed behind, leaving a gap between them. They now move together.
- **Editing an address keeps your place.** Typing inside a URL in the address bar no longer throws the cursor to the end after every character.
- **Going back to a page you started on works the first time.** A navigation back to the page a tab first opened, after the page had moved on, no longer does nothing.
- **Quitting doesn't crash.** A shutdown crash after using private windows is gone; Solara turns off a Chrome service it never used.
- **Translate says why it failed.** Instead of a bare "Unable to Translate", the message gives the reason, waits for a language download to finish, and one bad piece of a page no longer cancels the rest.
- **Safe mode keeps your bookmarks available.** Bookmarks show and open in safe mode; edits and sync pause until the next normal launch.

## Smaller

- Extension install, permission and pin dialogs are native sheets.
- Bookmark addresses use Chrome's spelling everywhere, and an address Chrome can't accept keeps your draft so you can fix it.
- Tab sleep runs natively and leaves pages that never settle alone sooner.
- Heavy-tab sampling runs only while Solara is the active app.
