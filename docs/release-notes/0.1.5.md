## Fixed

- **Sign-in windows show their page again.** A sign-in window a site opens, like "Continue with Google" on claude.ai
  or Slack's connect flow, showed its address strip over an empty dark window, so there was nothing to sign in to.
  The strip at the top painted its background over the whole page. It now stays in its own strip, and the page shows
  below it.
- **New Window opens on the profile you're in.** ⌘N, the command bar and the shortcut opened every new window on your
  default profile. A new window now uses the profile of the window you chose it in, and one opened from a private
  window uses the profile that private window came from.
- **Closing the last tab keeps a window that has pinned tabs.** ⌘W on the last tab closed the whole window, pinned
  tiles and pinned groups with it. The window now stays, on a New Tab page, with its pins. Windows without pins close
  as before.
- **Muted sites' notifications make no sound.** A site you'd muted, or a muted tab, still played the notification
  sound. Notifications from it now arrive silently, and the same site in another profile keeps its sound.
- **The hidden sidebar stays hidden while you're in another app.** With the sidebar set to hide, moving the pointer
  to the left edge of the screen slid it out even while another app was in front. It now peeks only while Solara is
  the active app, and slides away when you switch to another app, unless you're using something in it.
- **Sync no longer skips a change it failed to save.** If Solara couldn't save a batch of sync changes to disk, the
  next try treated the batch as saved. A crash right after could lose recent changes such as pinned tab order or
  saved passwords waiting to sync.

## New

- **Remove a profile from sync once it's gone everywhere.** A profile you deleted on every Mac kept appearing in
  Settings › Sync under "On your other devices", with Add to This Mac. That row now has Remove from Sync…, which
  names every profile it removes before you confirm. It never touches a profile on this Mac, and a Mac that still
  has the profile with sync on brings it back after its next sync.
- **Moved tabs land where a new tab would.** Moving tabs to another window, with Move to Window or the tab menu, used
  to put them at the end. They now go where Settings › Tabs › "Add new tabs" says: at the top, at the bottom or next
  to the window's current tab, joining that tab's group if it has one. Several tabs keep their order.
- **Little Solara can keep new-tab links.** Settings › General › "Open new-tab links from Little Solara in" chooses
  Main Window (as before) or Little Solara. With Little Solara, a link that opens a new tab opens a second Little
  Solara window, keeping the sign-in or payment flow attached to the page that opened it. ⌘-click still opens the
  link behind, in the main window.

## Smaller

- Solara checks a downloaded update more strictly before it prepares it to launch.
