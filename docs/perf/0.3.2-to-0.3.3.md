# 0.3.2 → 0.3.3 release gate

0.3.3 (build 99, v0.3.3 on 58c8319d) carries engine 71b12894a4f0 (Chromium 157.0.8103.50) and moves the native API
from 40 to 43, so native-bench ran the control with 0.3.2's own bench bundle (`--control-bundle`, the bundle 0.3.2's
gate built from its release commit) and js-bench each app's own `main.jsbundle`. Candidate `dist/0.3.3/export/Solara.app`
(signed and notarized); control `dist/0.3.2/export/Solara.app`. Both with `SOLARA_NATIVE_BOOKMARKS=1`, measured on
2026-11-12 on the Hill Studio under the perflab lock, interleaved, screen locked (paint and frame rows pending).

The first candidate (66162e18) failed on store-listener time; b2677aab cut the lazy-profiles listener's per-update
work (about 200 µs to 6 µs at 200 tabs) and the second candidate (58c8319d) is the one measured below. It still
failed the gate's "same or better" rule on the rows listed; the owner chose to ship it and fix them in 0.3.4.

effects, native calls. The remaining listener time is the two new store subscribers (lazy profiles, pinned-link

first switch, the cost lazy profiles moves out of launch. The memory rows fit uBlock Origin Lite's WebKit lists
(+8 to 15 MB when they landed). Tab switch to visible (23 ms) and new window (about 90 ms) are unchanged.
