# 0.4.0 → 0.4.1 release gate

0.4.1 (build 103, candidate e85b49f1; release f1c33cdf) keeps Chromium 157.0.8103.50 and moves native API 64 → 65.
Native window layout stays off by default in both releases. native-bench used the candidate's bench bundle and the
retained 0.4.0 API-64 bundle; js-bench used each app's own shipped `main.jsbundle`. Candidate
`dist/0.4.1/export/Solara.app` is signed and notarized; control `dist/0.4.0/export` points to the retained 0.4.0 export.
Both with `SOLARA_NATIVE_BOOKMARKS=1`, ad hoc copies on both sides (`BENCH_SIGN_IDENTITY=-`), offline, measured on
2026-11-16 on the Hill Studio under the perflab lock, interleaved, with `caffeinate -d`. native-bench: launch x6,
session and standalone windows x2 per app. js-bench: three alternating runs per app, all six exited 0.

**HOLD.** One timing row exceeds the owner's 15% limit with separated ranges; the ratchet and sheet host also fail.

**Shipped by the owner's call** (2026-11-16, "ship it"). Cause of the close row and the 22 close/open counts: with
New tabs at Top, the openClose journey's last close selects the first restored tab, which is cold and loads on
selection; at Bottom it selects a tab warmed at launch. The same 0.4.1 build set to Bottom passes every ceiling at
0.4.0's timing, and prewarming that one tab at Top removes the difference, so it is the cost of landing on an unloaded
tab, not of closing. The close/open ceilings are raised for it. A separate waste found on the way (strip-only bridge
commits serialized to JS) is fixed for 0.4.2. sheet-host fails as it did for 0.4.0, unchanged code.

Smoke: 70/70, exit 0, no skips, including Sparkle update, carryover, clean quit and popup checks. The initial run was
69/70 because carryover expected Bottom to survive the intentional first-launch Top override (`11e1986e`). The
test now requires Top when reading a 0.4.1 target, preserving strict checks of the other settings; seven focused
comparison cases and the full smoke rerun pass. This changes the test, not the candidate.

Ratchet: FAIL after its automatic second run, 22 counts over, 621 below their ceilings. The repeated increases
concentrate in tab close: commits 211 ceiling → 217, browser listener calls 1020 → 1326, page store updates
20 → 24, and toolbar renders 30 → 36. Open `onStoreCommit` also rises 118 → 135. The native island/scrim
(`780b17c4`), profile slot (`f50e3a00`), fade (`9b86b1d9`), launch override (`11e1986e`) and new-tab mark
(`35f8042f`) do not establish an exact explanation for these interaction counts. No ceiling was raised or lowered.

Host harnesses: initial full run 17/19; after fixing the swipe harness's resource lookup, 18/19. `35f8042f` added
SolaraUI resources, but the manually linked swipe host did not locate the bundle. Setting
`PACKAGE_RESOURCE_BUNDLE_PATH` to its products directory fixes it; the focused rerun passes. The initial SIGTRAP
crash report's UUID matches that harness binary. `sheet-host` still fails "ending busy must allow dismiss" on both
runs. Its source and NativeSheets.swift are unchanged from the 0.4.0 control, whose gate recorded the same failure;
the owner's current rule still blocks release on a host failure.

Values below are medians; parentheses give min–max and n. Raw results are retained under
`/Users/andrewbenson/.cache/solara-lead/work/rel041/codex/gate41/`: `perf-gate/native/`, `perf-gate/js/`,
`native-table.md`, `js-compare.log` and `metric-analysis.json`.

increase to that intended behavior. There is no justified ceiling increase.
