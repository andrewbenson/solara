headline: The sidebar now takes instructions from the terminal.

## New

- **Arrange the sidebar from the command line.** `solara sidebar` lists your groups, folders and tabs, and can make groups and folders, move tabs into them, pin and unpin, rename, reorder, and send a tab to another profile or window. Each change is an ordinary sidebar edit, so ⌘Z undoes it and sync carries it. Add `--dry-run` to see what would change first; private profiles are never touched.
- **The solara command's agent skill knows the new commands.** `solara skills install` now teaches coding agents `solara sidebar` and the per-tab memory in `solara tabs`, and when to use them instead of `solara exec`.

## Fixed

- **Quitting saves your session all the way to disk.** On a clean quit, and when a session is saved on purpose, Solara now asks macOS to write it through to the disk itself, not just to put it in order, so a power cut right after quitting can't take the last changes with it. Everyday saves while you browse work as before.
- **uBlock Origin has its name back.** The extensions list showed it as `__MSG_extShortDesc__`. It shows its real name and description again.
- **The address bar keeps what you typed.** A completion that arrived late could fill in the wrong letters, and pressing Return on a fresh install could wait for the history index; both are fixed.

## Smaller

- Opening and closing tabs redraws the sidebar and tab strip less.
- Switching profiles refreshes only that profile's address bars.
- An animation scheduled just after a frame was drawn no longer waits for the next unrelated change.
- A hook's error reply arrives in the right order after a slow result.
