# 0.2.3 → 0.2.4 release gate

0.2.4 has no engine change (both provenance files name the same framework, built Nov 4 15:04, Chromium
156.0.8078.79) and both apps are native API 37,
so native-bench ran the candidate's bench bundle on both and js-bench runs each app's own `main.jsbundle`. The
launch path changes only by the text-selection Search button's default (off, turned off once for anyone who never
chose it) and the sleeping-tab settings reads; the rest is WebKit picture in picture, document picture in picture's
Back to Tab and the tab-sleep settings. The candidate is `dist/0.2.4/export/Solara.app` (signed and notarized, built
from c3440811, published as v0.2.4); the control is `dist/0.2.3/export/Solara.app`. Measured on 2026-11-05 on the Hill Studio under the
perflab lock and a QUIET window: native-bench interleaved (launch x6, session x2, windows), js-bench in two rounds of
3 alternating runs (control first, then candidate first), then a second interleaved session round (session x2) for
the one native row that separated. Ad hoc copies on both sides (`BENCH_SIGN_IDENTITY=-`). The screen was locked, so
every row that waits on a paint or a frame reads pending. cpu-cap wasn't running on the Hill Studio, so no run was
capped or paused.

## Result

Every gated row is the same within noise or better:

- **Launch:** window shown 596 ms (563–641) → 580 ms (558–598); JS running 487 ms (461–498) → 481 ms (448–497).
  Both overlap.
- **Idle and memory:** every row overlaps in both session rounds; memory medians are 14–31 MB lower on 0.2.4.
- **Idle wakeups/s at 20 tabs, renderers** separated in the first round by a hair, 10.2 (10.0–10.4) → 10.6
  (10.5–10.6), and overlapped in the second, 10.3 (9.7–10.9) → 11.1 (10.7–11.5). Not reproduced, so not a
  regression; 0.2.4 changes nothing in the renderers. The candidate's median is higher in both rounds, though:
  **one to watch** at the 0.2.5 gate.
- **App Nap check** (command answered after an idle minute) separated the other way in the first round,
  157 → 133 ms, and overlapped in the second (134 → 146 ms): noise.
- **Tab switch → visible** (informational) separated in the second round only, 30 → 34 ms (round 1: 31 against
  31 ms). It gates nothing.
- **js-bench:** rows that separate in both rounds: `bundle.hbcKB` 4579 → 4603 KB (+24 KB of new code),
  `startup.storeUpdates` 10 → 11 (one more update of `settings` at startup:
  `storeKeys` show `browser.settings` 1 → 2, the selection default's one-time migration adding its marker on js-bench's
  fresh seed; relaunching each of the six bench data folders a second time gives `browser.settings` 1 on both apps,
  with `selectionSearchOff` saved in 0.2.4's migrations, so it runs once per install (settings and their migrations
  are app-wide, not per profile), not on every launch) and `startup.listenerMs` 6.0 → 5.2–5.3 ms (lower). Bundle eval is 67 → 62 ms
  (overlapping). Other rows separate in one round only, in both directions.
- **Ratchet:** ok, 0 counts over, 583 below their ceiling (ceilings not lowered). Hover is pending (locked screen).

No `## Faster` section: nothing gated moved beyond noise.
